## Changes made to the original content

Imported pages are converted automatically. The conversion:

- converts VitePress syntax (custom containers, code groups, Vue tab and card components) to Starlight equivalents;
- shows code blocks as they appear on the official site: Twoslash setup code and type-query markers, which the
  official site hides, are removed, and diff markers (`[!code ++]`) become line highlights;
- replaces interactive widgets that need the official site's runtime with a link to the official page;
- removes HTML comments and Vue `<script setup>` blocks, which are not displayed upstream;
- rewrites internal links to this site, and points links to pages that are not imported back to the official site;
- leaves wording, API descriptions and code examples unchanged.

The [migration status](/project/migration-status/) page and the migration report in the repository list every
lossy step together with the original source.
