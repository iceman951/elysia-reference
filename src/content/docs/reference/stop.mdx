`stop` stops a server started with [`listen`](/reference/listen/). Its source documentation describes it as "Stop
server from serving".

## Signature

Declared as an instance property in `src/index.ts`:

```ts title="src/index.ts"
stop = async (closeActiveConnections?: boolean) => {
	await this['~adapter'].stop?.(this, closeActiveConnections)

	return this
}
```

## Parameters

<ApiParameters

		{

			type: 'boolean',
			optional: true,
			description:
				'Passed to the adapter. The source documentation example <code>app.stop(true)</code> is commented “Abruptly any requests inflight”.',
		},
	]}
/>

## Return value

A promise that resolves to the instance (`this`); the function is `async`.

## Behavior

- Delegates to the instance's adapter: the implementation awaits `this['~adapter'].stop?.(this, closeActiveConnections)`.
  The optional call (`?.`) means nothing is stopped by an adapter that does not implement `stop`.

## Code example

From the source documentation of `stop`:

```ts
const app = new Elysia()
	.get("/", () => 'hi')
	.listen(3000)

// Sometime later
app.stop()
```
