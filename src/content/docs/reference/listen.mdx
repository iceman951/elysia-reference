`listen` starts serving an Elysia instance. Its source documentation describes it as "Assign current instance to port
and start serving". Most examples in the guides end with it, for example [Quick Start](/quick-start/) and
[Routing](/essential/route/).

## Signature

Declared as an instance property in `src/index.ts`:

```ts title="src/index.ts"
listen = (
	options: string | number | Partial<Serve>,
	callback?: ListenCallback
) => {
	this['~adapter'].listen(this)(options, callback)

	return this
}
```

Referenced type, from `src/universal/server.ts`:

```ts title="src/universal/server.ts"
export type ListenCallback = (server: Server) => MaybePromise<void>
```

## Return value

The instance itself (`this`), so the result can be kept as the application, as in
`const app = new Elysia().get('/', () => 'Hello Elysia').listen(3000)`.

## Behavior

- Delegates to the instance's adapter: the implementation calls `this['~adapter'].listen(this)(options, callback)`.
  The [Quick Start](/quick-start/) shows the Node.js adapter being selected with `new Elysia({ adapter: node() })`.

## Code example

From [Quick Start](/quick-start/) (Bun):

```ts
import { Elysia } from 'elysia'

const app = new Elysia()
	.get('/', () => 'Hello Elysia')
	.listen(3000)

console.log(
	`🦊 Elysia is running at ${app.server?.hostname}:${app.server?.port}`
)
```

With a callback, from [Quick Start](/quick-start/) (Node.js):

```ts
import { Elysia } from 'elysia'
import { node } from '@elysia/node'

const app = new Elysia({ adapter: node() })
	.get('/', () => 'Hello Elysia')
	.listen(3000, ({ hostname, port }) => {
		console.log(
			`🦊 Elysia is running at ${hostname}:${port}`
		)
	})
```
