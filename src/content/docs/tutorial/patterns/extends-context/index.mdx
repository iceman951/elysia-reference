Elysia provides a context with small utilities to help you get started.

You can extend Elysia's context with:

1. [Decorate](/essential/handler/#decorate)
2. [State](/essential/handler/#state)
3. [Resolve](/essential/handler/#resolve)
4. [Derive](/essential/handler/#derive)

## Decorate

**Singleton**, and **immutable** properties that are shared across all requests.

```typescript
import { Elysia } from 'elysia'

class Logger {
    log(value: string) {
        console.log(value)
    }
}

new Elysia()
    .decorate('logger', new Logger())
    .get('/', ({ logger }) => {
        logger.log('hi')

        return 'hi'
    })
```

Decorated value it will be available in the context as a read-only property, see [Decorate](/essential/handler/#decorate).

## State

A **mutable** reference that is shared across all requests.

```typescript
import { Elysia } from 'elysia'

new Elysia()
	.state('count', 0)
	.get('/', ({ store }) => {
		store.count++

		return store.count
	})
```

State will be available in **context.store** that is shared across every request, see [State](/essential/handler/#state).

## Resolve / Derive

[Decorate](/essential/handler/#decorate)

value is registered as a singleton.

While [Resolve](/essential/handler/#resolve), and [Derive](/essential/handler/#derive) allows you to abstract a context value **per request**.

```typescript
import { Elysia } from 'elysia'

new Elysia()
	.derive(({ headers: { authorization } }) => ({
		authorization
	}))
	.get('/', ({ authorization }) => authorization)
```

Any **returned value will be available in context** except status, which will be send to client directly, and abort the subsequent handlers.

Syntax for both [resolve](/essential/handler/#resolve), [derive](/essential/handler/#derive) is similar but they have different use cases.

Under the hood, both is a syntax sugar <small>(with type safety)</small> of a lifecycle:

- [derive](/essential/handler/#derive) is based on [transform](/essential/life-cycle/#transform)
- [resolve](/essential/handler/#resolve) is based on [before handle](/essential/life-cycle/#before-handle)

Since [derive](/essential/handler/#resolve) is based on [transform](/essential/life-cycle/#transform), which means that data isn't validated, and coerce/transform yet. It's better to use [resolve](/essential/handler/#resolve) if you need validated data.

## Scope

[State](/essential/handler/#state)

, and

[Decorate](/essential/handler/#decorate)

are shared across all requests, and instances.

<br />

[Resolve](/essential/handler/#resolve)

, and

[Derive](/essential/handler/#derive)

are per request, and have an encapsulation scope <small>(as they're based on life-cycle event)</small>.

If you want to use a resolved/derived value from a plugin, you would have to declare a [Scope](/essential/plugin/#scope).

```typescript ins={5}
import { Elysia } from 'elysia'

const plugin = new Elysia()
	.derive(
		{ as: 'scoped' },
		({ headers: { authorization } }) => ({
			authorization
		})
	)

new Elysia()
	.use(plugin)
	.get('/', ({ authorization }) => authorization)
	.listen(3000)
```

  We can use [resolve](/essential/handler/#resolve) to extract age from query.

  ```typescript
  import { Elysia, t } from 'elysia'

  class Logger {
  	log(info: string) {
  		console.log(info)
  	}
  }

  new Elysia()
  	.decorate('logger', new Logger())
  	.onRequest(({ request, logger }) => {
  		logger.log(`Request to ${request.url}`)
  	})
  	.guard({
  		query: t.Optional(
  			t.Object({
  				age: t.Number({ min: 15 })
  			})
  		)
  	})
  	.resolve(({ query: { age }, status }) => {
  		if(!age) return status(401)

  		return { age }
  	})
  	.get('/profile', ({ age }) => age)
  	.listen(3000)
  ```
